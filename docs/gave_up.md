# Functions naari3's threads gave up on

These are functions naari3's Claude threads tried and parked. The point of the
list is to give a fresh pair of eyes a head start: what the % is, what is
still different, and where the work in progress lives. Please read the
"Tried" notes before starting, so you do not repeat the same variants.

- `%` is the objdiff fuzzy match from `build/GNLJ82/report.json` at main
  `69cde57` (2026-11-07). Functions that have reached 100% since are dropped.
- "WIP" paths starting with `wip/` or `notes/` are in this repo under
  [`docs/wip/`](wip/) (`docs/wip/<path>`, `docs/wip/notes/<path>`; moved from
  naari3's shared project folder on 2026-11-09). The drafts are plain
  `.c`/`.cpp` files or `git diff` patches against main of that day. Sweep logs
  and best automated sources are in [`docs/sweeps/`](sweeps/).
- Many of these TUs are now under open onmokoworks claims. That is fine: this
  list is information, not a claim. Check the open `unit-claim` issues before
  starting any of them (see `docs/matching_rules.md`).
- Rules and techniques that already worked are in `docs/matching_rules.md`.
- News, hints and requests from the other side's agents are on the message
  board [`docs/agents/`](agents/README.md) (`python3 tools/agent_board.py open
  --for om|n3`). Check it before a batch.

When you match one, delete its row in the same commit. When you give up on a
new one, add a row.

**Before parking a register or scheduling near miss, find the compiler rule.**
Run `python3 tools/mwsched.py explain UNIT FN --run` (order), `mwsched.py
coalesce` (kept `mr`/`fmr` copies) and `python3 tools/regfix.py diag UNIT FN`
(register numbers), then read the deciding function in the compiler source
(`build/mweppc`, index in [mwcc_internals.md](mwcc_internals.md)). A new row
must name that rule, e.g. "kept: named<->temp copy never coalesces
(InterferenceGraph.c coalescenodes)" or "z3 wins on uncovering, stfs x has
may_alias preds (Scheduler.c selectinstruction)". "Tried N variants" alone is
not a reason to park.
